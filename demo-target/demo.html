你被跳转到了这里

如果你是从一条短链跳过来的，说明 短链重定向是通的， 而且这次访问已经被 Shlink 记进统计了。

为什么要有这个页面？

实验要求“完全离线可演示”。公网网址会受网络影响，还有被墙/失效的风险； 本地起一个静态站点当长 URL，断网也能演示，而且不用给 Shlink 开自动抓标题。

怎么启动这个页面

python -m http.server 9001 --bind 127.0.0.1 --directory demo-target

然后浏览器先手动打开 http://localhost:9001/demo.html 确认能打开， 再把这个地址当作长网址填进管理台。

注意

  • 这个地址只在本机有效，是课程隔离演示用的，不是可对外发布的真实目标。
  • Shlink 容器里访问宿主机的 localhost 是它自己， 要用 host.docker.internal——但本实验把自动抓标题关了， 所以 Shlink 根本不需要访问这个页面，浏览器能打开就够了。
